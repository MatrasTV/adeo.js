# adeo.js

Единый скрипт Tampermonkey для работы с прайсами в административной панели ADEO. Файл для установки: [adeo.user.js](adeo.user.js), версия **3.0.0**.

## Установка

1. Установите расширение Tampermonkey в браузере.
2. Создайте в Tampermonkey новый скрипт.
3. Замените содержимое редактора полным содержимым файла `adeo.user.js` и сохраните.
4. Откройте или обновите нужную страницу административной панели.

Отдельной сборки и установки библиотек не требуется. Скрипт выбирает функции по адресу страницы и обрабатывает элементы, которые появляются после её загрузки.

Автор скрипта — [MatrasTV](https://github.com/MatrasTV). В метаданных указаны [репозиторий](https://github.com/MatrasTV/adeo.js), [обращения по работе скрипта](https://github.com/MatrasTV/adeo.js/issues) и ссылки для установки и проверки обновлений из последнего релиза GitHub. Значком служит аватар автора. Для работы ссылок релиз должен содержать вложение с точным именем `adeo.user.js`; при выпуске обновлений увеличивайте `@version` в этом файле.

## Возможности

### Анализ позиций прайса на продаваемость

Страница: `https://admin.adeo.pro/admin/admin_pricerelevance/list` (также с параметрами запроса или завершающим `/`).

- В поле загрузки `price` устанавливает фильтр файлов `.xlsx` и `.xls`.
- Заполняет поле «Добавить колонки после» (`outStart`) значением `5`.
- Снимает флажки «Средняя цена в заказах» (`orders_avg_cost`) и «Макс. цена в заказах» (`orders_max_cost`).
- Заполняет поле «Начать статистику с» (`start_date`) датой за предыдущий календарный месяц в формате `ГГГГ-ММ-ДД`. Использует местную дату браузера. Если соответствующего дня нет, выбирает последний день предыдущего месяца: например, для 31 марта — 28 февраля, а в високосный год — 29 февраля.

Начальные значения полей и флажков устанавливаются один раз для каждого найденного элемента. Последующие ручные изменения сохраняются; для вновь созданных элементов формы начальные значения применяются заново.

### Пересечения

Страницы: `https://admin.adeo.pro/admin/supplier/price/compare/*`.

| Возможность | Действие |
| --- | --- |
| «Новый прайс» | Открывает `/admin/supplier/price/comparemode/{поставщик}/{версия}` с поставщиком и версией из текущего адреса `/admin/supplier/price/compare/{поставщик}/{версия}`. |
| «Сроки» | Собирает ключи `Cella/Склад` из загруженных строк поставщиков и показывает сроки из внутреннего сервиса. Закрытие — кнопкой `×`, клавишей Escape или нажатием на фон окна. |
| Флажок «Остаток» | Включает при первом обнаружении. Уже включённый флажок повторно не переключает. |
| Размер страницы таблицы | Добавляет варианты `10`, `50`, `100`, `500`, `1000`, `3000`, `5000`, `10000`, `100000`. Сохраняет текущее выбранное положительное число, даже если его нет в этом списке. Выбор размера остаётся за пользователем. |
| «Скопировать в буфер» | Добавляет кнопку в строку поставщика. Копирует актуальные значения строки в формате `Cella/Склад (Количество) Процент%`. |
| «Копировать пересечения» | Заменяет надпись «Топ 500 позиций» кнопкой копирования строк соответствующей вложенной таблицы. |
| Рабочая область | Устанавливает высоту первого блока `div.ui-jqgrid-bdiv` в `750px`. |

Копирование пересечений формирует текст для вставки в Excel: столбцы разделены табуляцией, строки — переводом строки. Порядок столбцов:

1. `pn_clean`.
2. `cbg_group_code`.
3. Пустой столбец.
4. `p_pn_draft`.
5. `p_pn_price_desc`.
6. `p_cost_eval`.
7. `p_remains`.
8. `cp_pn_draft`.
9. `cp_pn_price_desc`.
10. `cp_cost_eval`.
11. `cp_cost_eval_diff`.
12. `cp_remains`.

Копируются только строки, уже загруженные в соответствующую таблицу на странице. Скрипт не загружает другие страницы таблицы. Пустые последние столбцы сохраняются; табуляции и переводы строк внутри значения заменяются пробелами.

### Загрузка нового прайса и статусы импорта

Страницы: `https://admin.adeo.pro/admin/supplier/price/comparemode/*`.

В поле загрузки `input[type="file"][name="upfile"][id="pricefile"]` устанавливает фильтр `.xlsx` и `.xls`. Текст элементов `.job-status` выделяет жирным и окрашивает без учёта регистра:

| Фраза в статусе | Цвет |
| --- | --- |
| «уже идет импорт» | Красный |
| «задание в очереди» | Золотистый (`#CC9933`) |
| «импорт окончен» | Зелёный |
| Другая фраза | Убирает заданный скриптом цвет, сохраняет жирное начертание |

Оформление применяется к существующим и добавленным статусам, в том числе при изменении текста внутри вложенных элементов. Если статус содержит несколько перечисленных фраз, приоритет соответствует порядку строк таблицы.

## Внутренний сервис сроков

Кнопка «Сроки» выполняет запрос `GET https://192.168.3.19:6001/sroki`. Ожидается объект JSON, где ключ — `Cella/Склад`, а значение — срок. Например:

```json
{
  "123/Основной": "2 дня",
  "456/Резервный": "5 дней"
}
```

Для отсутствующего ключа отображается `—`. Нулевое значение срока сохраняется. Данные выводятся как текст.

Нужны доступ к внутренней сети, доверенный HTTPS-сертификат сервиса и разрешение сервера на запросы с `https://admin.adeo.pro` (CORS). Ограничения браузера на доступ к локальной сети также могут потребовать разрешения. Дополнительные привилегии Tampermonkey не запрашиваются (`@grant none`). Скрипт не отправляет сервису содержимое таблицы: сопоставление ключей выполняется в браузере.

Во время загрузки кнопка недоступна, повторное окно не создаётся. Запрос прерывается через 15 секунд. При ошибке сети, HTTP-ответа или формата данных появляется уведомление, подробности записываются в консоль браузера; таблица сроков при ошибке не открывается.

## Справочник функций

Все функции находятся внутри общей замкнутой области видимости и не добавляются в глобальный объект страницы.

| Функция | Назначение |
| --- | --- |
| `init()` | Выбирает и запускает модуль по пути текущей страницы. |
| `observePage(update)` | Сразу вызывает обновление и повторяет его при изменении состава или текста DOM. Отключает наблюдение при `pagehide` и возобновляет при восстановлении страницы из кеша переходов браузера. |
| `setFileAcceptAttribute(selector)` | Устанавливает фильтр `.xlsx, .xls` для всех полей загрузки, найденных по селектору. |
| `fillFieldOnce(selector, value)` | Однократно задаёт значение каждого найденного поля и отправляет события `input` и `change`. |
| `setCheckboxOnce(input, checked)` | Однократно приводит флажок к заданному состоянию. Поддерживает обычный флажок и оформление iCheck. |
| `getPreviousMonthDate(now)` | Возвращает дату предыдущего календарного месяца с учётом числа дней в нём. По умолчанию использует текущую дату. |
| `initPriceRelevance()` | Подключает заполнение формы анализа продаваемости и фильтр файлов. |
| `updateTextStyle(element)` | Устанавливает жирное начертание и цвет статуса по его тексту. |
| `initCompareMode()` | Подключает оформление статусов импорта и фильтр загрузки нового прайса. |
| `getCellText(row, column, partial)` | Возвращает очищенный от пробелов по краям текст ячейки по `aria-describedby`; при `partial = true` ищет вхождение имени. Для отсутствующей ячейки возвращает пустую строку. |
| `getSupplierKey(row)` | Формирует ключ `Cella/Склад` из ячеек строки поставщика. |
| `getSupplierRows()` | Возвращает загруженные строки `tr.jqgrow`, содержащие обе ячейки ключа поставщика. |
| `copyText(text)` | Копирует текст через буфер обмена браузера; при ошибке показывает уведомление и пишет подробности в консоль. |
| `createButton(text, onClick, className)` | Создаёт кнопку с текстом, обработчиком и CSS-классом. Задаёт `type="button"`, чтобы нажатие не отправляло форму. |
| `renderSrokiModal(keys, dictionary)` | Создаёт окно с таблицей сроков, кнопкой закрытия и обработчиками закрытия. Не создаёт второе окно поверх существующего. |
| `closeModal()` | Вложена в `renderSrokiModal`: удаляет окно и обработчик клавиатуры, возвращает фокус на ранее активный элемент. |
| `handleEscape(event)` | Вложена в `renderSrokiModal`: закрывает окно по Escape. |
| `showSrokiModal(event)` | Загружает и проверяет словарь сроков, передаёт его для отображения; управляет тайм-аутом и состоянием кнопки. |
| `openNewPrice()` | Извлекает поставщика и версию из адреса пересечений и переходит к новому прайсу. При неподходящем формате пути переход не выполняется. |
| `addToolbarButtons()` | Добавляет в `.form-horizontal` кнопки «Новый прайс» и «Сроки» без дублирования. |
| `activateCheckboxWithText(text)` | Находит флажки по точному тексту подписи внутри `.checkbox label` и включает их однократно. |
| `updateDropdownValues(dropdown)` | Однократно обновляет варианты размера страницы, сохраняя текущий выбор. |
| `addCopyButtons()` | Добавляет кнопки копирования в строки поставщиков. Считывает значения при нажатии. |
| `copyIntersections(header)` | Собирает 12 столбцов строк связанной вложенной таблицы и копирует их для вставки в Excel. |
| `addCopyHeaderButtons()` | Находит заголовки «Топ 500 позиций» во вложенных таблицах и добавляет кнопки копирования без дублирования. |
| `increaseWorkAreaHeight()` | Устанавливает высоту первого блока таблицы в `750px`. |
| `initCompare()` | Подключает все инструменты страницы пересечений через общий наблюдатель DOM. |

## Настройки и ограничения

- `SROKI_URL` в начале файла — адрес сервиса сроков.
- `PAGE_SIZES` — доступные размеры страницы таблицы.
- Значения `5`, `750px` и разрешённые расширения заданы в соответствующих функциях.
- Атрибут `accept` фильтрует выбор файлов в браузере; он не проверяет содержимое файла и не заменяет серверную проверку.
- Буфер обмена требует разрешения браузера. При отказе появляется уведомление.
- Размер `100000` может существенно замедлить страницу и увеличить нагрузку на сервер. Скрипт добавляет этот вариант, но не выбирает его автоматически.
- Работа зависит от адресов страниц и HTML-разметки ADEO: имён полей, CSS-классов и `aria-describedby`. При изменении панели селекторы могут потребовать обновления.
- Переходы между разделами рассчитаны на обычную загрузку страницы. Переключение разделов без перезагрузки отдельно не обрабатывается.

## Проверка

Автоматические проверки запускаются из каталога проекта в Node.js со встроенным модулем `node:test`, без установки дополнительных библиотек:

```text
node --check adeo.user.js
node --test tests/adeo.test.cjs
```

Проверки охватывают расчёт даты, однократное заполнение полей и переключение флажков, оформление статусов, формат копирования пересечений, переход к новому прайсу, фильтры файлов, ошибки буфера обмена и сервиса сроков, выбор модуля по адресу и жизненный цикл наблюдателя. Они используют имитации элементов страницы и не заменяют проверку на действующей панели ADEO с её версией iCheck и доступом к внутреннему сервису.
